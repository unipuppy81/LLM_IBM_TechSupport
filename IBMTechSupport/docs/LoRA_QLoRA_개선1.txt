D : 가중치를 0.05로 감소시키면서 가장 높은 답변 정확도를 기록했으나 정상 거부율이 0%로 감소했다.
E : 가중치를 0.175로 설정한 결과 정상 거부율 75.86%, 잘못된 거부율 63.64%, 답변 정확도 16.88%를 기록했다. 답변 가능 여부 판별력이 전체 후보 중 가장 높았다.

Loss 가중치를 낮출수록 정상 거부율과 잘못된 거부율이 함께 감소하는 커플링 현상이 관찰됐다.
Loss Weighting은 과도한 답변 거부 성향을 완화했으나 답변 가능 여부의 판별 문제를 완전히 해결하지는 못했다.


## 최종 선정
E(0.175)를 Stage 2의 잠정 비교 기준으로 채택한다. 이후 closed-book LoRA 실험의 Baseline으로 재사용한다.
선정 근거 : 정상 거부율 50% 이상 충족, 답변 정확도 개선, 전체 후보 중 가장 높은 Youden's J 및 가장 낮은 Reference Unsupported 비율.

자동 평가 결과는 사람의 검증이 필요하며, 판별력 개선의 통계적 유의성은 검증되지 않았다.
데이터 균형 조절, Balanced Sampling, Hard Negative, 데이터 증강은 이 단계에서 미실행. QLoRA 재학습은 보류.

- 학습의 distractor 문서는 휴리스틱으로 선택되었으며 실제 불충분 근거인지 검증된 것은 아니다.
- 근거 문서명 중복 7개는 별도로 검토해야 한다. 이는 질문 ID 중복과 구분되며, 문서 독립 일반화는 검증되지 않았다.
- 기존 Judge는 참조 정답과 문서를 기반으로 평가하며 모델이 실제 받은 근거에 대한 Faithfulness를 직접 검증하지 않는다.

- TRAIN_Q395 : 질문은 ITCAM for HTTP Server와 IHS의 AIX 버전 호환성이나 정답은 IBM HTTP Server 8.5.5.9의 Apache 보안 수정 내역. 질문 핵심 요구와 정답이 맞지 않음.
- TRAIN_Q584 : 질문은 CVE-2017-1741, 근거 문서 제목과 내용은 CVE-2017-1731. CVE 대응 관계 재검증 필요.

위 3건은 전체 Train 데이터에서의 오류 건수 추정치가 아니며, 실제 매핑 또는 정답 생성 단계의 검증 필요성을 보여주는 확인 사례임.

### 학습한 사실과 반대되는 생성 답변

- TRAIN_Q446 : IBM DataPower는 관련 Bash CVE의 영향을 받지 않는다는 정답과 반대로 SFT/DAPT 모두 '취약하다'고 생성. SFT Token F1은 약 0.4324여도 핵심 사실은 틀림.
- DEV_Q064 : IBM MQ와 MQ Appliance의 Triple-DES/SWEET32 취약 버전 질문에 두 모델 모두 영향이 없다고 부정. 문서의 영향 버전 정보와 모순.
- TRAIN_Q466 : 분실한 ISDS Seed는 복구할 수 없다는 문서와 달리 DAPT+SFT가 기존 값을 복구하는 임의 절차 생성.
- TRAIN_Q436 : DAPT+SFT는 BPM 임시 파일 문제에 전체 /tmp 또는 Windows Temp 디렉터리 삭제를 제안. 근거는 BPM 생성 잔여 파일의 선별 삭제이므로 위험한 과잉 절차임.

기술적 오류 유형 : 핵심 사실 반전, 제품/버전 혼동, 임의 명령·파일 경로 및 과잉 해결 절차.
단순 표현 차이 또는 Token F1 계산 문제만으로 설명되지 않음.

## 진단 결론과 한계

1. Train에서도 답변 재현 F1이 낮고, 실제로 학습 정답과 반대되는 기술적 사실을 생성한 사례가 있음.
2. Validation만 실패하는 전형적인 일반화 부족 패턴은 관찰되지 않았으나 일반화 문제 자체가 없다고 확정할 수는 없음.
3. QA 품질 검증을 수행했음에도 질문/정답/근거 정합성 오류가 일부 남아 있음.
4. 학습 목표가 Causal LM / SFT Cross-Entropy이며 기술적 참·거짓을 직접 최적화하는 지표는 아님.
5. Token F1/Exact Match는 기술적 정확성 또는 지식 보유량의 직접 측정치가 아님.
6. DAPT, LoRA Rank, Epoch의 한계치에 도달했다고 확정할 자료는 부족함.
7. Validation은 반복 모델 선정에 사용한 개발 세트이며 독립 Test 성능을 의미하지 않음.
